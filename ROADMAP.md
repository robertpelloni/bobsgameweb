# ROADMAP: okgame Structural Milestones
- [ ] **Phase 1: Recovery & Foundation** - Indexing legacy assets, stabilizing the world graph, and implementing the import pipeline.
- [ ] **Phase 2: Feature Parity** - Achieving 1:1 functionality with the v8830 engine (dialogue, audio, movement, collision).
- [ ] **Phase 3: Modernization** - Implementing WebGPU rendering, advanced particle systems, and FFT-driven visualizers.
- [ ] **Phase 4: Expansion** - Developing new regional clusters, multiplayer hardening, and mobile optimization.
