# SUBMODULES & ENGINE ANALYSIS

This document maintains the canonical list of submodules tracked in the `/submodules/` directory. These external open-source projects have been added so we can dissect, analyze, and assimilate their features into our ultimate omni-engine `bgeditor`.

## Sprite and Art Tools
- [aseprite](https://github.com/aseprite/aseprite) - Leading pixel art tool (C++). Key features: timeline, cels, layers, palette management.
- [sprite-studio-64](https://github.com/tstamborski/sprite-studio-64) - Web-based C64/Amiga sprite editor.
- [stipple-effect](https://github.com/stipple-effect/stipple-effect) - Java-based pixel art editor.
- [csprite](https://github.com/csprite/csprite) - Lightweight C/C++ sprite editor.
- [raster-master](https://github.com/RetroNick2020/raster-master) - Vintage-style raster sprite editor.
- [voidsprite](https://github.com/counter185/voidsprite) - C++ sprite editor.
- [Pixelorama](https://github.com/Orama-Interactive/Pixelorama) - Built with Godot, excellent UI patterns.
- [PixiEditor](https://github.com/PixiEditor/PixiEditor) - C#/WPF/Avalonia based. Good layer system.
- [LibreSprite](https://github.com/LibreSprite/LibreSprite) - Open-source fork of Aseprite.
- [rx](https://github.com/cloudhead/rx) - Minimalist pixel editor written in Rust.
- [piskel](https://github.com/piskelapp/piskel) - Web-based, excellent animation preview loop.

## Tilemap Tools
- [Tile-Studio](https://github.com/Wiering/Tile-Studio) - Classic Windows tilemap editor with code-generation capabilities.
- [tilemap-studio](https://github.com/Rangi42/tilemap-studio) - Excellent for Gameboy/Retro hardware tilemap formats.
- [tilemap-editor](https://github.com/blurymind/tilemap-editor)
- [tactile](https://github.com/albin-johansson/tactile)
- [Simple-Sprite-Tile-2D](https://github.com/wmltogether/Simple-Sprite-Tile-2D)
- [bottled-up-tilemap](https://github.com/Dark-Peace/bottled-up-tilemap)
- [DTile](https://github.com/MagnonGames/DTile)
- [tiled](https://github.com/mapeditor/tiled) - The industry standard. Key features: TMX/TSX XML formatting, isometric/hexagonal support, object layers.
- [OgmoEditor3-CE](https://github.com/Ogmo-Editor-3/OgmoEditor3-CE) - Web/Electron based level editor focusing on entities and collision grids.

## Voxel and 3D Tools
- [blockbench](https://github.com/JannisX11/blockbench) - Excellent low-poly 3D modeling and animation, native web tech.
- [goxel](https://github.com/guillaumechereau/goxel) - C++ voxel editor.

## Legacy and Other Tools

- [retro-game-editor](https://github.com/haroldo-ok/retro-game-editor)
