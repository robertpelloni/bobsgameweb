# GEMINI.md — Gemini / Antigravity Model Instructions

> **Master Governance Reference:** Read and follow **[AGENTS.md](./AGENTS.md)** in full first. All universal repository directives, versioning standards (`VERSION.md`), BelowNormal process priority rules, binary retention policies, and documentation mandates live in `AGENTS.md`.

## Directives Summary (Mirrored from `AGENTS.md`)
1. **Analyze Deeply**: Always analyze the full project state, including `HANDOFF.md`, `ROADMAP.md`, `TODO.md`, `VISION.md`, `MEMORY.md`, `STRUCTURAL_MAP.md`, and `CHANGELOG.md`.
2. **Document Everything**: Input information and your findings must be documented in comprehensive, FULL extreme detail. Never gitignore `.memory/`, sessions, or `*.db`.
3. **Comment Heavily**: Comment your code in depth—what it's doing, why, side effects, optimizations, alternate methods.
4. **Version Control**: Every build should have a new version number. Update `VERSION.md` (which should only contain the version string). Update `CHANGELOG.md`. Commit and push with the version number in the commit message.
5. **Autonomy**: Do not stop. Do whatever research needs to be done. Keep going until all planned features are 100% implemented. Never clean built binaries; run heavyweight tasks at `BelowNormal` priority.
6. **Submodules**: Ensure all linked/referenced projects (`submodules/bobui`, `juce`, `ultimatepp`) are updated recursively and documented.
